# Security

## Reporting a vulnerability

Please report it privately: **Security → Report a vulnerability** on this repository's page.
Do not open a public issue for it. Include the version, the system and the steps to
reproduce. A report from Settings → Diagnostics helps; it contains no links, file names or
addresses.

Only the newest version gets fixes. Installed copies are offered updates automatically.

## What is protected, and how

The design is documented in [docs/adr](docs/adr/) (017 redirects and cookies, 021 browser
bridge, 022 and 026 updates, 025 stored credentials). The
[hardening report](docs/hardening-report.md) lists the checks and what was not verified.
